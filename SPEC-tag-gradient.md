# Дополнение к SPEC.md: выделение меток градиентом (вариант 3)

Это дополнение к основной спецификации `SPEC.md`. Оно меняет **только фон карточки**
у сортов с меткой. Всё остальное (метка-плашка под фото, звезда за логотипом,
плашка «RGB», цвета, шрифты, порядок) — как в `SPEC.md`.

Визуальный референс: `docs/rgb-tag-variants.png`, пример **«3. Градиент»**.

---

## 1. Идея

У карточки с меткой фон — горизонтальный градиент:

- **слева** (у логотипа, где стоит метка) — цвет метки;
- **справа** (название, цены) — «свой» цвет карточки: оранжевый у Robim Good,
  голубой у нулёвки, обычный фон у остальных.

Так одна карточка показывает оба сигнала: метка — слева, бренд — справа,
и они не спорят за одну заливку.

## 2. Правило

```css
.tap.has-tag {
  background: linear-gradient(90deg,
    color-mix(in srgb, var(--tag-color) 28%, transparent) 0%,
    var(--card-fill) 55%);
}
```

| Переменная | Что подставлять |
|---|---|
| `--tag-color` | цвет метки этого сорта (таблица в разделе 3) |
| `--card-fill` | заливка карточки без метки (таблица в разделе 4) |

- Направление — слева направо (`90deg`), без наклона.
- Цвет метки — **28%** непрозрачности у левого края.
- К **55%** ширины карточки градиент полностью переходит в `--card-fill`,
  дальше фон ровный. Так зона цен всегда остаётся спокойной.
- Скругление, поля и рамка карточки — как в `SPEC.md` (рамка прозрачная).

## 3. Цвет метки (`--tag-color`)

Те же цвета, что у плашки метки и звезды (`SPEC.md`, раздел 7):

| Метка | `--tag-color` |
|---|---|
| NEW | `#5b9a6e` |
| % | `#a8473a` |
| 1,5=2 | `#d9b45f` |
| TOP | `#e9e1d2` |
| 0,0 | `#7fb6cf` |

## 4. Заливка справа (`--card-fill`)

| Сорт | `--card-fill` | Пример |
|---|---|---|
| Robim Good | `color-mix(in srgb, #e57a24 16%, transparent)` | NEW → оранжевый |
| Нулёвка (`abv === 0`) | `color-mix(in srgb, #7fb6cf 15%, transparent)` | NEW → голубой |
| Остальные | `transparent` (обычный фон секции) | NEW → фон |

Порядок проверки: сначала нулёвка, потом Robim Good, потом «остальные»
(нулёвка Robim Good — голубая, как в `SPEC.md`).

## 5. Особые случаи

- **Без метки** — градиента нет, карточка как в `SPEC.md`: Robim Good — ровная
  оранжевая заливка, нулёвка — ровная голубая, остальные — без заливки.
- **Нулёвка с меткой «0,0»** (метка поставлена автоматически или в админке):
  цвет метки совпадает с заливкой — рисовать **ровную голубую заливку**,
  без градиента.
- **Нулёвка с другой меткой** (например NEW): градиент
  от зелёного к голубому — по общему правилу.
- **Метка не распознана** (нет в таблице раздела 3) — без градиента.

## 6. Пример CSS

```css
.tap               { --card-fill: transparent; }
.tap.rg            { --card-fill: color-mix(in srgb, var(--rg) 16%, transparent); }
.tap.zero          { --card-fill: color-mix(in srgb, var(--zero) 15%, transparent); }
.tap               { background: var(--card-fill); }

.tap.t-new   { --tag-color: var(--t-new); }
.tap.t-sale  { --tag-color: var(--t-sale); }
.tap.t-promo { --tag-color: var(--t-promo); }
.tap.t-top   { --tag-color: var(--t-top); }
.tap.t-zero  { --tag-color: var(--zero); }

.tap[class*=" t-"]:not(.zero.t-zero) {
  background: linear-gradient(90deg,
    color-mix(in srgb, var(--tag-color) 28%, transparent) 0%,
    var(--card-fill) 55%);
}
```

Классы `rg`, `zero`, `t-*` — те же, что в эталоне `index.html`.

## 7. Критерии приёмки

- [ ] Robim Good OKTOBERFEST с NEW: слева зелёный оттенок у логотипа,
      плавно переходит в оранжевую заливку к середине карточки.
- [ ] Обычное пиво с меткой (например Kronenbourg с «%»): слева гранатовый
      оттенок, справа обычный фон секции.
- [ ] Robim Good ZERO (метка «0,0»): ровная голубая заливка, без градиента.
- [ ] Сорта без меток выглядят как раньше.
- [ ] Зона цен (правая половина карточки) у всех карточек одного типа —
      одного ровного цвета, без переходов.
- [ ] Звезда и плашка метки не изменились.
