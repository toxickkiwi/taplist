# Дополнение к SPEC.md: паттерн Robim Good, фон меток, цены, скругление карточек

Это дополнение к основной спецификации `SPEC.md`. Где правила расходятся,
**приоритет у этого файла**. Всё, что здесь не упомянуто, — как в `SPEC.md`.

Визуальный референс: `docs/rgb-pattern-checker.png`.

Размеры даны в `rem` (база 10px, подгонка под экран — `SPEC.md`, раздел 4).

---

## A. Выделение Robim Good паттерном

### A.1. Что меняется по сравнению с SPEC.md

| Было (`SPEC.md`, раздел 9) | Стало |
|---|---|
| Оранжевая заливка карточки Robim Good | **Заливки нет**, фон карточки обычный |
| — | Бледный оранжевый паттерн «ROBIM GOOD» по всей карточке |
| Плашка «RGB», оранжевое название пивоварни | Без изменений |
| Название пива «Robim Good …» | Без изменений, не сокращать |

Паттерн рисуется у всех сортов, где пивоварня начинается с «Robim Good»
(после нормализации названий, `SPEC.md` раздел 2.1), включая нулёвку Robim Good.

### A.2. Вид паттерна

Слова «ROBIM GOOD» в **шахматном порядке**: каждое слово в своей клетке,
каждый второй ряд сдвинут на полклетки. Вся сетка повёрнута на **−20°**
(слова поднимаются слева направо).

| Параметр | Значение |
|---|---|
| Текст | `Robim Good`, заглавными (`text-transform: uppercase`) |
| Шрифт | Fira Sans 800, `1.3rem`, `line-height: 1`, `letter-spacing: .08em` |
| Цвет | `--rg` (`#e57a24`) |
| Прозрачность | `opacity: .18` |
| Ширина клетки (шаг по горизонтали) | `11.8rem`, слово по центру клетки |
| Высота ряда (шаг по вертикали) | `1.6rem` |
| Сдвиг чётных рядов | `5.9rem` (ровно полклетки) |
| Поворот сетки | `rotate: -20deg` |
| Покрытие | вся карточка, без пустых углов |

### A.3. Слои и обрезка

Паттерн — **нижний слой** карточки: под номером, логотипом, звездой, меткой,
текстом и ценами. Он не должен перекрывать ничего.

Паттерн обрезается по **скруглённым углам карточки** (раздел C), но сама
карточка `overflow: hidden` **не получает** — иначе обрежется звезда за
логотипом (`SPEC.md`, раздел 7.1), которая выходит за край карточки.
Поэтому паттерн кладётся в отдельный слой-обёртку:

```html
<article class="tap rg">
  <div class="tap-bg"><div class="pattern">…строки…</div></div>
  <div class="num">…</div> … остальное содержимое …
</article>
```

```css
.tap { position: relative; isolation: isolate; }
.tap-bg {
  position: absolute; inset: 0; z-index: -1;
  border-radius: inherit;      /* скругление как у карточки */
  overflow: hidden;            /* обрезаем только фон */
  background: var(--card-fill, transparent);
}
.pattern {
  position: absolute; inset: -20rem -12rem;   /* запас, чтобы после поворота не было пустых углов */
  rotate: -20deg;
  display: flex; flex-direction: column;
  font: 800 1.3rem/1 "Fira Sans", sans-serif;
  text-transform: uppercase; letter-spacing: .08em;
  color: var(--rg); opacity: .18;
  white-space: nowrap; pointer-events: none;
}
.pattern > div { display: flex; flex: none; height: 1.6rem; align-items: center; }
.pattern > div:nth-child(even) { translate: 5.9rem 0; }
.pattern span { flex: none; width: 11.8rem; text-align: center; }
```

Строк и слов генерировать с запасом (ориентир: 40 строк × 22 слова) — лишнее
обрежется. Паттерн статичный, не анимируется.

Важно: строки ряда **не должны сжиматься** (`flex: none` у строки), иначе
шахматка схлопнется в сплошную текстуру.

## B. Фон карточки у сортов с меткой

Метка выделяется **заливкой всей карточки** цветом метки, 22%:

```css
.tap.t-new   { --card-fill: color-mix(in srgb, #5b9a6e 22%, transparent); }
.tap.t-sale  { --card-fill: color-mix(in srgb, #a8473a 22%, transparent); }
.tap.t-promo { --card-fill: color-mix(in srgb, #d9b45f 22%, transparent); }
.tap.t-top   { --card-fill: color-mix(in srgb, #e9e1d2 22%, transparent); }
.tap.zero    { --card-fill: color-mix(in srgb, #7fb6cf 15%, transparent); }
```

Заливка лежит в `.tap-bg` (раздел A.3), паттерн — поверх заливки.

| Сорт | Фон | Паттерн |
|---|---|---|
| Robim Good с меткой | цвет метки 22% | да |
| Robim Good без метки | обычный | да |
| Другое пиво с меткой | цвет метки 22% | нет |
| Другое пиво без метки | обычный | нет |
| Нулёвка (любая) | голубой 15% | только если Robim Good |

- Метка «0,0» у нулёвки: фон голубой 15% (метка и фон одного цвета).
- Звезда за логотипом и плашка метки — без изменений (`SPEC.md`, разделы 7, 7.1).
- Градиент из `SPEC-tag-gradient.md` **не используется** в этом варианте.

Референс утверждён для метки NEW; для остальных меток правило то же, цвет — из таблицы.

## C. Скруглённые углы карточек

| Элемент | Скругление |
|---|---|
| Карточка сорта (`.tap`) | **`1.2rem`** |
| Фон и паттерн карточки (`.tap-bg`) | `border-radius: inherit` (то же, что у карточки) |
| Рамка выделения (если используется) | то же `1.2rem` |
| Секция категории | `0.6rem` (без изменений) |
| Логотип | `0.6rem` (без изменений) |
| Метка | `99px`, полностью круглые края (без изменений) |
| Плашка «RGB» | `0.4rem` (без изменений) |

- Скругление видно только у карточек с фоном (метка, нулёвка) или паттерном
  (Robim Good). У обычных карточек фона нет — углы не видны, это нормально.
- Внутренние поля карточки: `1rem 1.4rem 1.8rem` (снизу больше — под метку,
  которая наполовину выходит под логотип).
- Между карточками в сетке — зазор `0.8rem 1.6rem` (`SPEC.md`), чтобы
  скруглённые фоны соседних карточек не слипались.

## D. Цены

Заменяет пункт «Цены» в `SPEC.md`, раздел 6.

### D.1. Раскладка

Колонка справа в карточке, сетка из двух колонок «объём | цена»:

```
0,5 л   9 р.
1 л    13,5 р.
```

```css
.prices {
  display: grid; grid-template-columns: auto auto;
  gap: .2rem 1rem; align-items: baseline; white-space: nowrap;
}
```

- **Всё выровнено по левому краю**: подписи объёма начинаются с одной вертикали,
  цены — с другой.
- Колонка цен по ширине — по содержимому (`auto`), не растягивается.
- Цены не переносятся на новую строку и не обрезаются; при нехватке места
  уменьшается весь экран (подгонка, `SPEC.md` раздел 4), а не цены.

### D.2. Типографика

| Часть | Шрифт | Цвет |
|---|---|---|
| Объём («0,5 л») | Fira Sans 600, `1.8rem` | `--fg` (`#f3ede2`) |
| Сумма («13,5») | Montserrat 900, `2.4rem`, `font-variant-numeric: tabular-nums` | `--price` (`#d9b45f`) |
| Валюта («р.») | тот же шрифт, `0.6em` от суммы, без пробела после числа | `--price` |

### D.3. Форматирование

| Вход (`amountMinor`) | На экране |
|---|---|
| `800` | `8 р.` → сумма `8`, валюта `р.` |
| `1350` | `13,5 р.` |
| `1325` | `13,25 р.` |
| `1000` | `10 р.` |

- Делитель — запятая, лишние нули после запятой убирать (`13,50` → `13,5`, `8,00` → `8`).
- Подпись объёма: из `price.label`, нормализовать `500 мл` → `0,5 л`, `1000 мл` → `1 л`.
  Десятичный разделитель — запятая.
- Значки тары (кружка/бутылка, `price.container`) **не выводить**.

### D.4. Количество цен

- Обычно 2 строки (0,5 л и 1 л) — порядок как в админке.
- 1 цена — одна строка, выровненная по центру карточки по вертикали.
- 3 и больше — показывать все строки; подгонка экрана уменьшит размер.
- Цен нет — колонку не выводить, текст карточки занимает её место.
